# Лабораторная работа 2. Вариант 1

Интерпретатор классической двузначной логики, сильной логики Клини K3
и логики Лукасевича L3. Python 3.9 или новее, без внешних библиотек.

- [План решения](План_решения_ЛР2.md).
- [Отчёт: все формулы и отношения варианта 1](Отчёт_ЛР2_вариант_1.md).
- [Примеры для демонстрации](Сценарии_проверки_ЛР2.md).

## Запуск

Из корня репозитория:

```bash
python lab2/lab2_variant1.py
```

Меню: 1 — вычислить значение; 2 — таблица и свойства; 3 — сравнить логики;
4 — проверить следование; 5 — примеры варианта 1; 0 — выйти.
При вводе посылок в меню используйте разделитель `;`.

Также доступны команды для воспроизводимого запуска:

```bash
python lab2/lab2_variant1.py eval "p -> q" --logic K3 --values p=1/2 q=1/2
python lab2/lab2_variant1.py table "(p & !p) & q" --logic K3
python lab2/lab2_variant1.py compare "p -> p"
python lab2/lab2_variant1.py compare "p -> q" --values p=1/2 q=1/2
python lab2/lab2_variant1.py entail "q" --premise "p" --premise "p -> q" --logic L3
python lab2/lab2_variant1.py variant
python lab2/lab2_variant1.py report --output lab2/Отчёт_ЛР2_вариант_1.md
```

`entail --table` дополнительно печатает все оценки с колонками A1, A2, …, B.
Без `--premise` проверяется общезначимость заключения.
`compare --logics K3 L3` выбирает системы для сравнения.
Если у `compare` задана оценка, показываются значения на ней и свойства
формулы на полном домене каждой системы.

## Синтаксис и значения

| Операция | Допустимые записи |
| --- | --- |
| Отрицание | ¬, !, ~ |
| Конъюнкция | ∧, &, && |
| Дизъюнкция | ∨, \|, \|\| |
| Импликация | →, ->, =>, ⊃, ⇒ |

Переменные — латинские идентификаторы, например p, q, x1, value_2.
Регистр значим. В ЛР2 f и t — обычные переменные.
Константы и знак равенства внутри формул не поддерживаются условием.
Приоритеты: ¬ > ∧ > ∨ > →. Цепочки → группируются слева, как в ЛР1;
для другой группировки используйте скобки.

Оценки задаются как `p=0 q=1/2 r=1`; допустима запись `0.5`.
В C2 допустимы только 0 и 1, в K3 и L3 — 0, 1/2 и 1.
Программа проверяет пропущенные, лишние и повторные оценки переменных.

## Смысл результатов

Выделено только значение 1. Общезначимая формула равна 1 на всех оценках,
выполнимая — хотя бы на одной. Невыполнимость не означает тождественную
ложность: p∧¬p в K3 и L3 не достигает 1, но при p=1/2 равна 1/2.

Контрпример следованию: все посылки равны 1, заключение равно 0 или 1/2.
Если посылки несовместимы, следование считается выполненным формально,
а отсутствие совместных моделей сообщается отдельно.

В сравнительных таблицах прочерк означает недопустимую оценку для системы,
а не значение 0. Число строк разное: 2^n для C2 и 3^n для K3/L3.
Значения сравниваются только там, где соответствующие системы допускают
одну и ту же оценку. Свойства считаются по полному домену каждой системы.

## Файлы и проверка

- logic.py — AST, парсер, точная семантика, анализ и следование.
- variant1.py — F1–F5, R1–R4 и построение отчёта.
- lab2_variant1.py — меню и команды.
- test_logic.py — таблицы операций, свойства, ошибки и независимая сверка варианта.
- test_cli.py — запуск настоящего консольного процесса.

```bash
python -m unittest discover -s lab2 -p "test_*.py" -v
python -m unittest discover -s lab1 -p "test_*.py" -v
```

Лимиты: 10000 символов формулы, 80 уровней вложенности/дерева,
100000 оценок в одном полном переборе. При превышении выводится отказ
от вычисления из-за ресурсов, без утверждения о ложности формулы.
Успешный анализ, включая отрицательный результат следования, завершает
команду с кодом 0. Ошибка ввода или отказ по лимиту — с кодом 2.
