# Демонстрация ЛР2. Вариант 1

Команды выполняются из корня репозитория. Формулы заключаются в кавычки.
В меню можно выполнить те же проверки, выбрав нужный режим.

## 1. Различие импликации K3 и L3

```bash
python lab2/lab2_variant1.py eval "p -> q" --logic K3 --values p=1/2 q=1/2
python lab2/lab2_variant1.py eval "p -> q" --logic L3 --values p=1/2 q=1/2
```

Ожидается соответственно 1/2 и 1. Это пример из условия.

## 2. Не заданы все переменные

```bash
python lab2/lab2_variant1.py eval "p -> q" --logic K3 --values p=1
```

Ожидается сообщение «Недостаточно данных: не заданы q», код завершения 2.
Программа не должна придумывать значение q.

## 3. Полуистина недопустима в классической логике

```bash
python lab2/lab2_variant1.py eval "p" --logic C2 --values p=1/2
```

Ожидается сообщение о недопустимом значении, код 2.

## 4. Невыполнимость и тождественная ложность

```bash
python lab2/lab2_variant1.py table "p & !p" --logic C2
python lab2/lab2_variant1.py table "p & !p" --logic K3
```

В C2 результаты 0,0: невыполнима и тождественно ложна.
В K3 результаты 0,1/2,0: невыполнима, но не тождественно ложна.

## 5. Одна формула в трёх системах

```bash
python lab2/lab2_variant1.py compare "p -> p"
```

Общезначима в C2 и L3; не общезначима в K3.
В строке p=1/2: C2 — прочерк, K3 — 1/2, L3 — 1.

## 6. Сравнение при заданной оценке

```bash
python lab2/lab2_variant1.py compare "p -> q" --values p=1/2 q=1/2
```

C2 — оценка недопустима; K3 — 1/2; L3 — 1.
Свойства самой формулы p→q при этом совпадают: она выполнима и не общезначима.

## 7. Корректное следование MP

```bash
python lab2/lab2_variant1.py entail "q" --premise "p" --premise "p -> q" --logic L3 --table
```

Проверяются 9 оценок, контрпримеров нет. Следование выполняется.

## 8. Отсутствует меньшая посылка

```bash
python lab2/lab2_variant1.py entail "q" --premise "p -> q" --logic K3
```

Следование не выполняется. Контрпример p=0,q=0: p→q=1, q=0.
Это результат полного семантического анализа, а не поиск доказательства как в ЛР1.

## 9. Несовместимые посылки

```bash
python lab2/lab2_variant1.py entail "q" --premise "p" --premise "!p" --logic L3
```

Совместных моделей посылок нет. Программа сообщает об этом отдельно.
Следование выполняется формально.

## 10. Контрпример может давать 1/2, а не только 0

```bash
python lab2/lab2_variant1.py entail "p -> p" --logic K3
```

Список посылок пуст. При p=1/2 заключение равно 1/2, поэтому следование не выполняется.

## 11. Ошибка синтаксиса

```bash
python lab2/lab2_variant1.py table "p ->" --logic K3
```

Ожидается ошибка формулы, без таблицы и без traceback. Код завершения 2.

## 12. Все примеры варианта 1

```bash

python lab2/lab2_variant1.py report --output lab2/Отчёт_ЛР2_вариант_1.md
```
