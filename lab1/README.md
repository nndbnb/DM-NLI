# Лабораторная работа №1 — вариант 1

Консольный верификатор шагов доказательства в исчислении высказываний.
Python 3.9 или новее. Внешние библиотеки не требуются.

## Аксиомы и правила

Используются переменные, константа ложности `f` и импликация `⊃`.

```text
A1: p⊃(q⊃p)
A2: (s⊃(p⊃q))⊃((s⊃p)⊃(s⊃q))
A3: ((p⊃f)⊃f)⊃p
```

Правила вывода:

- MP: из `A⊃B` и `A` выводится `B`.
- β: одна переменная во всех вхождениях заменяется одной и той же ППФ.
  Частичная подстановка и одновременная замена разных переменных запрещены.
  Константа `f` не заменяется.

По формулировке задания аксиомы доступны для MP и β с начала сеанса.
Также доступны все ранее принятые формулы. Проверяемая строка становится
источником только после успешной проверки.

## Синтаксис

Импликацию можно записывать как `⊃`, `->`, `=>`, `→` или `⇒`.
Переменные — латинские идентификаторы, например `p`, `q`, `x1`.
Пробелы игнорируются.

## Устройство программы

- `Variable`, `FalseConst`, `Implication` представляют узлы AST.
- `tokenize()` и `Parser` преобразуют строку в дерево.
- `find_beta()` проверяет полную подстановку одной переменной.
- `ProofVerifier` хранит аксиомы, правила и историю с обоснованиями.
- `verify()` проверяет синтаксис, повтор, аксиому, MP и β в этом порядке.
- Сравнение формул выполняется по структуре деревьев.

Неудачная проверка не меняет историю. Повтор ранее принятой формулы
не создаёт новую строку. Программа проверяет введённые шаги, а не ищет
полное доказательство автоматически.

## Запуск

Из корня репозитория:

```bash
python lab1/lab1_variant1.py
```

Команды: `axioms`, `list`, `clear`, `help`, `exit`.
`clear` очищает историю, сохраняя доступность аксиом.

Пример двух шагов без предварительного ввода A1:

```text
(p⊃(q⊃p))⊃(q⊃(p⊃(q⊃p)))
q⊃(p⊃(q⊃p))
```

Первый шаг — β из A1 с заменой `p` на `p⊃(q⊃p)`.
Второй — MP из первого шага и A1.

## Тесты

Из корня репозитория:

```bash
python -m unittest discover -s lab1 -p "test_*.py" -v
```

Тесты проверяют синтаксис, левую группировку импликаций, скобки,
сохранение структуры при печати, допустимые и недопустимые β-подстановки,
доступность аксиом, MP, ошибки ввода, повторы и очистку истории.
